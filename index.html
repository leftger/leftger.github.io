🚀 Install & Bootstrap

Automated, idempotent Linux workstation provisioning tailored for bare-metal C & async Rust development.

curl --proto '=https' --tlsv1.2 -sSf https://leftger.github.io/bootstrap.sh | sh

🦀 Rust & Embedded

  • Rustup: Stable toolchain + rust-src, clippy, rustfmt
  • Targets: Cortex-M (M0+, M3, M4F, M33), RISC-V
  • Tools: probe-rs, cargo-binstall, cargo-deny, cargo-llvm-cov

🔌 Hardware & Toolchains

  • GNU ARM: gcc-arm-none-eabi, gdb, newlib, openocd
  • Serial & Debug: tio serial I/O, probe-rs hardware rules
  • Cross-Platform: Native support for Linux & macOS (Homebrew)

⚡ Terminal & Shell

  • Zsh: Oh-My-Zsh with autosuggestions & syntax highlighting
  • Plugins: sudo, cargo, rust, z, extract, my-completions
  • Modern CLI: btop, mosh, tmux, ripgrep, fd, bat, fzf

💻 Modern Editors

  • Zed: High-performance code editor (~/.local/bin/zed)
  • Vim: Badwolf theme, line numbers, whitespace stripping
  • Tmux: TrueColor, vi mode keys, 10k scrollback

🎨 Curated Dotfiles

  • Tmux: Mouse support, TrueColor, vi keys, dark status bar
  • Git: Conventional commit template (~/.gitmessage), alias.pa
  • Standards: .editorconfig, .hushlogin (silent login MOTD)

🛠️ Maintenance & Productivity

  • full-upgrade: One-stop updater for APT, Rust, Zed, WSL (alias: up)
  • Aliases: mcd, enhanced cdr (with TAB completion), refreshenv
  • WSL Interop: cdw, wslview BROWSER, systemd boot config
